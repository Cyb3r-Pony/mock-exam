# Mock Exam

A self-contained practice-exam and flashcard trainer. Single HTML file, no build step,
no dependencies, no network calls. Open `index.html` in any browser, desktop or mobile.

## Use

- **Flashcards** — tap or click to reveal, swipe left/right to move, mark known / not known.
- **Practice exam** — 25 / 50 / 100 question sessions, or a full blueprint-weighted paper.
  Modes: blueprint-weighted, weak-area drill, long-form cases, single section, single
  module, and re-drill of questions previously answered wrong.
- **Rotation** — on by default, serves the questions you have seen least first, so
  consecutive sessions do not repeat until the bank has been worked through.
- **Progress** — per-section accuracy and coverage. Stored in `localStorage` on the
  device, so it is per-browser and never leaves the machine.

## Mobile

Responsive down to small phones, 44px touch targets, safe-area insets for notched
screens, swipe navigation, and installable to the home screen via *Add to Home Screen*.

## Privacy

Everything runs client-side. No analytics, no external requests, no data leaves the browser.
